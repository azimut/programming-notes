*** radiosity

https://wiki.povray.org/content/HowTo:Use_radiosity

#+begin_src pov
  global_settings {
    radiosity {
      adc_bailout     0.01  // keep or use "0.01 / brightest_emissive_object"
      always_sample   off   // off = use pretrace stage samples
      brightness       F
      count            35   // ,N (optional n° directions)  number of rays sent
      error_bound      1.8  // fraction of error tolerated - shape of shadows - +flatter_shadows
      gray_threshold   0.0  // ratio to gray out the color bleed
      low_error_factor 0.5  // aka error_bound used on pretrace
      max_sample       F
      media           true
      maximum_reuse  0.200  // effective radius ratio
      minimum_reuse  0.015  // effective radius ratio
      nearest_count    5    // ,N - 1 .. 20, second value is optional, smaller than first, used for adapative pretrace
      normal          true
      pretrace_start   0.08 // 0.0 ~ 1.0 percentage, size of the blocks in the mosaic preview
      pretrace_end     0.04 // 0.0 ~ 1.0 percentage, size of the blocks in the mosaic preview
      recursion_limit  2    // ~ 20
      subsurface      true
    }
  }
#+end_src

*** photons

- https://wiki.povray.org/content/Reference:Photons
- adds:
  - reflective caustics (eg: mirrors can reflect light)
  - refractive caustics (eg: lenses can focus light)
- emitted from the lights
- use with interior, pigment, finish{irid refraction}
- does refractions don't require "hollow"

#+begin_src pov
