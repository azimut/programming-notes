- uses =serial pooling= shift register protocols
- latch and clock pins can be shared between controllers
- AB turbo buttons, are equivalent to pressing AB repeatedly
- pins
  - vcc, gnd (supports 5v and 3.3v)
  - 3 line/pins serial communication
    |-----+--------------+----------------------------------------|
    | IN  | latch/strobe | sent to capture the current state      |
    | IN  | clock        | on each, the next button state is read |
    | OUT | data         | single bit, of the button status       |
    |-----+--------------+----------------------------------------|
    - order
      - a
      - b
      - start
      - select
      - up
      - down
      - left
      - right
