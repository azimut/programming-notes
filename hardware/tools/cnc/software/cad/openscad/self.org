* language

- polimorfic functions by type and cardinality
- two pass compiler/interpreter
- ends with ";"
- comments with "//" and "/* */"
- variables are defined once, the last one if many
  - aka no recursive definition
  - but there are scopes
- new: functions as values, closures

** transformations

https://en.wikibooks.org/wiki/OpenSCAD_User_Manual/Transformations

the same one can be nested/cascaded, no ";"

- translate([x,y,z]) { }
- rotate(a) - rotates around z
- rotate(a, [x,y,z]) - rotates a degrees in x,y,z vector direction
- rotate([a1,a2,a3]) - rotates around origin, on each angle
- scale([x,y,z]) - scales by vector
- resize([x,y,z]) - scales to vector size, 0 does nothing on that axis
- mirror([x,y,z])
- multmatrix([1,0,0,10],
             [0,1,0,20],
             [0,0,1,30],
             [0,0,0, 1])
- color([r,g,b,a]) - from 0.0 - 1.0
- color("black")
- color("#fafafa")
- offset: generates a new 2D outline from an existing one
  - offset() - r=1  chamfer=false
  - offset(N) - N defaults to radius
  - offset(r) - radius around figure
  - offset(delta) - delta away from figure
  - offset(delta, chamfer)
- minkowski() - sum of childs
- hull() - wraps childs, hull projection on xy plane
- projection() - 3d into 2d
- fill() - removes holes from polygons

** modules

*** BOSL2 attachments

- an anchor is a point with a direction outward of the object
- see: ~show_anchors()~
- 2 objects can be =attached= by
  - the anchor= of the 2nd/child
  - the ~position(TBFRLB)~ of the 1st/parent
  - the ~orient(anchor=TBFRLB)~ to change anchor orientation
  - by putting _one after the other_, in the same command (;)
